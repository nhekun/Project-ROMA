# Security Policy

ROMA Launcher is a private experimental project, not production software. It is provided as-is and may contain defects, including security or privacy-related defects. Use it only in environments where you accept that risk, and review the source and requested permissions before installation.

## Reporting a concern

Please do not publish sensitive vulnerability details in a public issue. Since this repository is private, contact the repository owner through the private channels available to you, and include a concise description, affected revision, impact, and steps to assess the issue. Avoid sharing real personal data or secrets in a report.

There is no guaranteed response time, fix, or security advisory process. Do not assume that a report has been received or resolved until the owner confirms it.
